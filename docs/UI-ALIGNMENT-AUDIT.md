# UI 정렬 점검 (UI Alignment Audit) — 2026-06-19

전체 페이지를 Chrome(claude-in-chrome MCP)으로 모바일 폭(약 526px)에서 캡처하고,
각 화면의 버튼·텍스트·아이콘 정렬을 소스(Tailwind 클래스)와 대조하여 점검했다.

## 점검 범위 (캡처한 화면)

| 경로 | 화면 | 정렬 상태 |
| --- | --- | --- |
| `/login` | 로그인 | OK |
| `/` | 홈(피드) | OK (하단 탭바 아이콘만 보정) |

대부분의 화면은 일관된 Tailwind 유틸리티(`flex items-center`, `justify-*`, `min-h-[44px]`)로
정렬이 잘 맞아 있다. 아래 3건만 실제 정렬 어긋남으로 확인되어 수정한다.

## 발견된 정렬 문제 및 수정안

### 1. 스레드 헤더 제목이 가운데 정렬되지 않음 (확실한 결함)

- **파일**: `frontend/src/pages/Thread.tsx` (`<header>`, 약 317–350행)
- **현상**: 헤더는 `flex items-center` 구조로 `[뒤로 버튼] · [제목(flex-1, text-center)] · [북마크][메뉴]` 배치다.
  왼쪽은 버튼 1개(약 36px), 오른쪽은 버튼 2개(약 80px)라 좌우 폭이 비대칭이다.
  `flex-1` 영역이 한쪽으로 밀려, `text-center` 제목이 헤더의 실제 중앙보다 **왼쪽으로 치우쳐** 보인다.
- **수정**: 제목 왼쪽에 오른쪽 버튼 1개 폭만큼의 **투명 스페이서**(`h-9 w-9 shrink-0`)를 추가해
  좌우 클러스터 폭을 맞춘다 → 제목이 헤더 정중앙에 위치.

### 2. 하단 탭바 이모지 아이콘의 수직 정렬 불균일

- **파일**: `frontend/src/layout/BottomTabBar.tsx`
- **현상**: 🏠/🔍/✏️/👤 이모지가 `text-lg leading-none`으로만 렌더되어, 글리프마다
  베이스라인이 달라 아이콘이 미세하게 위아래로 들쭉날쭉하다.
- **수정**: 각 아이콘을 **고정 높이의 flex 중앙 정렬 박스**(`flex h-6 items-center justify-center`)로 감싸
  4개 아이콘이 동일한 수직 중심선을 공유하도록 한다(라벨 baseline도 균일해짐).

### 3. Composer 첨부(＋)·전송(↑) 버튼 크기 불일치

- **파일**: `frontend/src/components/Composer.tsx`
- **현상**: 첨부 버튼은 `h-9 w-9`(36px), 전송 버튼은 `h-11 w-11`(44px)로 크기가 다르다.
  입력 행이 `items-end`라 작은 첨부 버튼이 바닥에 붙으면서 ＋ 아이콘이 ↑ 아이콘보다 낮게 보인다.
- **수정**: 첨부 버튼을 전송 버튼과 동일한 `h-11 w-11`로 맞춰 두 아이콘 중심선을 일치시킨다.

## 수정하지 않은 항목 (의도된 디자인)

- **채팅 버블의 아바타 하단 정렬**(`items-end`): 일반적인 채팅 UI 패턴으로 의도된 배치.
- **버블 작성자/시간 라벨의 `px-1` 들여쓰기**: 버블 본문(`px-3`) 대비 의도적 미세 들여쓰기.
- **이모지 자체의 글리프 편차**: OS·폰트에 종속되는 부분으로, 정렬 박스(#2)로 흡수 가능한 범위만 보정.
